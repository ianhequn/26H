# PT / ONNX / KModel 精度一致性评测报告

## 评测设置

- 验证集：完全相同的80张ROI图片（包含空标签背景图）
- 标准AP：imgsz=224, conf=0.001, NMS IoU=0.60, max_det=5
- 部署统计：conf=0.25, NMS IoU=0.45, max_det=5
- 匹配规则：IoU >= 0.50的一对一匹配

## 自动诊断

情况C（离线部分）：PT、ONNX、KModel离线指标接近。若K230现场仍明显较差，应检查摄像头域差异、曝光、白平衡、运动模糊、ROI映射、板端预处理和阈值。

## 失败案例

- 失败图片记录数：27
- 量化回退图片：1
- 背景误检图片：0
- 多球漏检图片：18

详细逐图结果见 `results/per_image_results.csv`，模型差异见
`results/model_output_differences.csv`。失败标注图包含原始数据集画面，因此未放入公开仓库；
可使用统一评测脚本和 `--save-images` 在本地重新生成。

## K230现场层说明

本报告能够定位 PT → ONNX → KModel 的离线变化。KModel → K230实际部署还需要板端同一批图片回放结果或现场日志，不能用Simulator结果冒充板端实测。
